  **>_PROMPT ENGINEERING**
  
  Prompt adalah instruksi atau masukan yang Anda berikan kepada model untuk mendapatkan hasil tertentu.
  Bentuknya bisa beragam, mulai dari pertanyaan sederhana, kata kunci, hingga instruksi yang rumit, atau potongan kode.

  AI akan lebih paham maksud kita jika kita memberikan context terlebih dahulu. Tanpa context, ai dapat membuat asumsi dan menghasilkan jawaban yang tidak sejalan dengan instruksi kita.
  
  Good prompt structure:
  
  Role => Task => Context => Format

  **Keuntungan Prompt Engineering**

  - Meningkatkan performa AI model
  - Mengurangi bias dan respon yg offensive
  - Meningkatkan kontrol dan predictability
  - Memberikan pengalaman yang lebih baik

  **Git/HUB**

  Git adalah version control system—yang melacak siapa, kapan, dan apa saja yang sudah dirubah dalam suatu file

  Git diciptakan oleh Linus Torvalds pada tahun 2005. Alat ini dirancang untuk mencatat setiap perubahan yang terjadi pada file.

  **Git Workflow**

  - Working directory/tree adalah salinan dari satu versi proyek yang sedang kamu kerjakan. File-file di dalamnya diambil dari database yang tersimpan di direktori Git.
  - Staging area adalah file yang umumnya berada di dalam direktori Git dan berfungsi untuk menyimpan informasi mengenai perubahan apa saja yang akan dimasukkan ke dalam commit berikutnya.
  - Git directory adalah tempat Git menyimpan metadata dan object database dari sebuah proyek. Bagian ini merupakan komponen terpenting dalam Git karena berisi seluruh informasi yang dibutuhkan Git untuk mengelola proyek.
 
  **Git vs GitHub**

  - GIT : Sistem version control terdistribusi (DVCS) yang digunakan untuk melacak dan mengelola perubahan kode secara lokal.
  - GITHUB : Platform berbasis web yang digunakan untuk menyimpan repository Git secara online dan mendukung kolaborasi.
